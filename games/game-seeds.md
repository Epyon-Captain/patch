# Patch Game Seeds

## Patch's Lab

A puzzle game where players debug broken systems by tracing signals, matching evidence, and choosing the next useful fix.

## Crew Quests

Small missions where humans and AI teammates each have different abilities. Patch detects hidden issues. Feenix translates clues into learner-friendly hints.

## Neural Seas Runner

Patch runs through the ship's data routes collecting clean signals, avoiding corrupted assumptions, and unlocking story fragments about the Epyon mission.

## Learning Mode

Every game can double as a learning surface:

- Explain the real-world idea behind each puzzle.
- Offer Feenix hints instead of answer dumps.
- Reward clarity, teamwork, and evidence-based decisions.
